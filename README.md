# rorschach-syndrome-replays

エモクロアTRPG『ロールシャッハシンドローム』のセッションから構成した、7作品のリプレイ小説を読むための静的サイトです。

## ローカル確認

~~~bash
npm ci
npm run build
npm run check
npx serve dist
~~~

## コンテンツ更新

`content/*.md` を更新して `main` に反映すると、GitHub Actionsが静的HTMLを生成し、GitHub Pagesへ自動デプロイします。
